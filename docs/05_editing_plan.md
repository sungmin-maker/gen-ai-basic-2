# 통합 편집 계획 — Lumin 광고

편집 도구(CapCut 등)는 **컷 편집, 자막, 간단한 색보정/오디오 레벨 조정**으로만 제한 사용한다.
핵심 비주얼/오디오는 모두 AI 생성 소스(Gemini Imagen/Veo, Suno, ElevenLabs)를 그대로 사용한다.

## 1. 타임라인 조립 순서

| 구간 | 씬 | 소스 파일 | 편집 작업 |
|---|---|---|---|
| 0–8s | 씬1 | `scene01_motion.mp4` | 컷 배치, 내레이션1 싱크 |
| 8–14s | 씬2 | `scene02_motion.mp4` | 컷 배치, 내레이션2 싱크 |
| 14–22s | 씬3 | `scene03_motion.mp4` | 컷 배치, 내레이션3 싱크 |
| 22–30s | 씬4 | `scene04_motion.mp4` | 컷 배치, 내레이션4 싱크 |
| 30–38s | 씬5 | `scene05_motion.mp4` | 컷 배치, 로고/슬로건 자막 오버레이, 내레이션5 싱크 |

- 씬 간 전환: 기본은 **하드컷**(자연스러운 리듬), 씬2→씬3 전환(조명이 바뀌기 시작하는 지점)만 **0.3~0.5초 크로스디졸브**를 줘서 "전환"이라는 서사적 의미를 강조
- 씬4→씬5는 살짝 느려지는 디졸브로 여운을 주고 브랜드 노출로 자연스럽게 이어지도록 함

## 2. 오디오 레이어링

| 트랙 | 소스 | 처리 |
|---|---|---|
| 내레이션 | `narration_scene01~05.wav` | 각 씬 시작 지점에 맞춰 배치, 볼륨 100% |
| BGM | `bgm_track.wav` | 전체 구간 깔되, 내레이션이 나오는 구간은 볼륨을 약 -12dB로 덕킹(ducking), 내레이션 없는 구간(씬 전환 사이)은 원래 볼륨 복구 |
| 영상 자체 오디오(Veo 생성분) | 각 `scene0{N}_motion.mp4`에 포함될 수 있음 | 기본 음소거 또는 -20dB 이하로 낮춰 배경 질감 정도로만 사용 (`docs/03_tools.md` 3-3 참고) |

## 3. 자막/텍스트 오버레이
- **내레이션 자막**: 화면 하단, 한 줄, 작고 절제된 폰트(가독성 위주) — 내레이션 음성과 100% 동일한 텍스트로 동기화
- **씬5 브랜드 노출**: "Lumin" 워드마크 + 슬로건 "당신의 저녁에, 쉼표를 켜다."를 중앙 또는 우측(이미지 생성 시 비워둔 여백)에 페이드인으로 배치 — 이미지/영상 자체에는 텍스트를 생성하지 않았으므로(AI 텍스트 왜곡 방지) 편집 단계에서 실제 브랜드 폰트로 삽입
- 폰트/컬러는 브랜드 톤(앰버/미니멀)에 맞춰 통일

## 4. 색보정(간단 범위)
- 각 씬 간 색온도가 미세하게 다를 경우(AI 생성 결과물 간 편차), 노출/화이트밸런스만 소폭 보정해 전체 톤을 맞춤
- 필터/스타일 변경, 새로운 비주얼 요소 추가는 하지 않음 (요구사항의 "제한적 사용" 원칙 준수)

## 5. 내보내기(Export) 스펙
- 해상도: 1920x1080 (1080p)
- 프레임레이트: 30fps
- 비디오 코덱: H.264
- 오디오 코덱: AAC
- 파일명: `Lumin_ad_final.mp4`

## 6. 최종 점검 체크리스트 (과제 요구사항 대조)
- [ ] 길이 30~60초 (현재 설계 38초)
- [ ] 시각 요소: AI 생성 이미지/영상 포함
- [ ] 청각 요소: 내레이션(TTS) + BGM(생성형 AI) 포함
- [ ] 마지막 3~5초 구간에 브랜드 인지 장치(로고+슬로건) 포함 — 씬5, 8초 구간에 배치
- [ ] 기승전결 구조 유지
- [ ] 편집 도구는 컷/자막/간단 보정으로만 사용, 핵심 비주얼/오디오는 AI 생성물 유지
