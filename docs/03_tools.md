# 도구 선정 — Lumin 광고

각 단계별 주 도구(Primary) + 대체 도구(Backup)를 지정하고, 선정 이유를 남긴다.
(요구사항: 이미지/비디오/오디오 각 1종 이상 사용, 대체 도구 준비)

## 1. 이미지 생성
- **Primary: Midjourney**
  - 이유: 따뜻한 조명/시네마틱 톤 표현에 강하고, `--sref`(Style Reference)로 전 씬에 걸쳐 색감·질감 일관성 유지 가능. 인물을 실루엣/뒷모습으로 처리할 때 구도 컨트롤이 좋음.
- **Backup: Adobe Firefly**
  - 이유: 상업적 이슈(저작권) 안전성이 높고, Midjourney 대기열/크레딧 문제 시 즉시 대체 가능. 다만 사실적 조명 표현은 다소 약함.

## 2. 비디오 생성(이미지→영상 변환)
- **Primary: Runway (Gen-3 Image to Video)**
  - 이유: 정적 이미지에 자연스러운 카메라 무빙(패닝/줌)과 미세한 연기·빛 입자 움직임을 부여하는 데 적합. 크레딧 절약을 위해 "정지 이미지 + 짧은 모션" 전략과 궁합이 좋음(제약사항 3-2 대응).
- **Backup: Kling / Pika**
  - 이유: Runway 대기열이 밀릴 경우 즉시 전환. Kling은 느린 카메라 무빙에, Pika는 짧은 루프 모션에 강점.

## 3. 오디오 생성
### 3-1. 배경음악(BGM)
- **Primary: Suno**
  - 이유: 로파이/잔잔한 피아노-신스 패드 프롬프트에 강하고, 씬별이 아닌 전체 트랙 1개로 뽑아 톤을 통일하기 쉬움(오디오 톤 미스매치 방지).
- **Backup: Udio**
  - 이유: Suno 크레딧 소진 시 대체. 분위기 묘사 프롬프트 호환성 유사.

### 3-2. 내레이션(TTS)
- **Primary: ElevenLabs**
  - 이유: 한국어 음성 자연스러움과 감정 톤(차분함) 조절이 우수, 보이스 하나를 전 씬에 고정해 일관성 유지.
- **Backup: Typecast**
  - 이유: 국내 서비스로 한국어 억양이 더 자연스러운 보이스 옵션 보유, ElevenLabs 대기/쿼터 이슈 시 전환.

## 일관성(스타일) 유지 전략
- **인물 미노출/실루엣 전략**: 얼굴 클로즈업을 최소화(씬 구성 참고)하여 씬마다 인물 얼굴이 달라지는 AI 특유의 문제를 원천 회피
- **Midjourney `--sref` 고정**: 첫 씬에서 생성한 이미지의 스타일 코드를 추출해 이후 모든 씬 프롬프트에 동일하게 적용 → 색감(앰버 톤), 질감, 조명 스타일 통일
- **고정 카메라 어휘 사용**: 모든 프롬프트에 `cinematic lighting, 35mm lens, shallow depth of field, warm amber tone` 등 동일 수식어를 반복 사용해 룩을 통일
- **BGM 단일 트랙 원칙**: 씬별로 따로 생성하지 않고 44초 분량 1개 트랙을 생성 후 편집 단계에서 볼륨만 조정 → 오디오 톤 미스매치 방지

## 크레딧/대기열 이슈 대응 (제약사항 반영)
1. 이미지 생성 단계에서 5씬 전체 키비주얼을 먼저 확정 (재생성 최소화)
2. 확정된 이미지만 비디오 변환 단계로 진행 (영상 생성 크레딧 절약)
3. Primary 도구가 대기열/쿼터 문제 시 즉시 Backup 도구로 전환, 스타일 프롬프트(색감/조명 수식어)는 동일하게 유지해 톤 차이 최소화
