# 도구 선정 — Lumin 광고

각 단계별 주 도구(Primary) + 대체 도구(Backup)를 지정하고, 선정 이유를 남긴다.
(요구사항: 이미지/비디오/오디오 각 1종 이상 사용, 대체 도구 준비)

## 1. 이미지 생성
- **Primary: Gemini (Imagen 3 기반 이미지 생성)**
  - 이유: 회사 팀 계정으로 이미 확보되어 있어 크레딧/접근성 문제가 가장 적음. 하나의 대화(채팅) 안에서 연속적으로 이미지를 생성·수정할 수 있어 스타일 일관성 관리가 용이함.
- **Backup: Midjourney 또는 Adobe Firefly**
  - 이유: Gemini 쪽 사용량 제한(팀 계정 쿼터, 동시 접속 제한 등)에 걸릴 경우 대체. Midjourney는 시네마틱 톤 표현에, Firefly는 저작권 안전성 측면에서 대체 우선순위로 둠.

## 2. 비디오 생성(이미지→영상 변환)
- **Primary: Gemini (Veo)**
  - 이유: 이미지 생성과 동일 계정/생태계로 연동되어 이미지→영상 파이프라인이 매끄러움. 확정된 키비주얼(이미지)을 그대로 입력해 이미지-투-비디오 방식으로 변환, 스타일 이탈을 최소화.
  - 참고: Veo는 프롬프트에 따라 네이티브 오디오(주변음)까지 함께 생성 가능 → 사용 여부는 4번 오디오 전략 참고.
- **Backup: Runway 또는 Kling/Pika**
  - 이유: Gemini/Veo 대기열·쿼터 문제 시 즉시 대체. Runway는 카메라 무빙 컨트롤이 세밀하고, Kling/Pika는 짧은 루프 모션에 강점.

## 3. 오디오 생성
### 3-1. 배경음악(BGM)
- **Primary: Suno**
  - 이유: 로파이/잔잔한 피아노-신스 패드 프롬프트에 강하고, 씬별이 아닌 전체 트랙 1개로 뽑아 톤을 통일하기 쉬움(오디오 톤 미스매치 방지). Gemini는 이미지/영상 전용으로 쓰고 오디오는 전문 도구로 분리.
- **Backup: Udio**
  - 이유: Suno 크레딧 소진 시 대체. 분위기 묘사 프롬프트 호환성 유사.

### 3-2. 내레이션(TTS)
- **Primary: ElevenLabs**
  - 이유: 한국어 음성 자연스러움과 감정 톤(차분함) 조절이 우수, 보이스 하나를 전 씬에 고정해 일관성 유지.
- **Backup: Typecast**
  - 이유: 국내 서비스로 한국어 억양이 더 자연스러운 보이스 옵션 보유, ElevenLabs 대기/쿼터 이슈 시 전환.

### 3-3. Veo 네이티브 오디오 처리 방침
- Veo가 생성하는 주변음(예: 옷 스치는 소리, 미세한 실내 소음)은 "선택적 참고 트랙"으로만 활용
- **BGM과 내레이션은 반드시 Suno/ElevenLabs로 별도 생성 후 편집 단계에서 믹싱** → 브랜드 사운드 톤(로파이/차분함)을 일관되게 통제하기 위함
- Veo 생성 시 오디오 옵션은 가급적 끄거나, 켜지더라도 최종 믹싱에서 볼륨을 낮춰 배경 질감 정도로만 사용

## 일관성(스타일) 유지 전략
- **인물 미노출/실루엣 전략**: 얼굴 클로즈업을 최소화(씬 구성 참고)하여 씬마다 인물 얼굴이 달라지는 AI 특유의 문제를 원천 회피
- **단일 대화(chat) 내 연속 생성**: Gemini는 Midjourney의 `--sref` 같은 명시적 스타일 코드가 없으므로, 하나의 대화 세션 안에서 이전 씬 이미지를 참고 이미지로 첨부하며 순차적으로 생성 → 모델이 맥락을 유지하도록 유도
- **고정 스타일 키워드 반복**: 모든 프롬프트에 동일한 수식어 세트를 반복 사용
  `warm amber tone, cinematic lighting, 35mm lens, shallow depth of field, minimal Korean apartment interior`
- **이미지→영상 파이프라인 고정**: Veo에 순수 텍스트 프롬프트가 아니라 "Gemini로 확정한 키비주얼 이미지"를 입력으로 사용해 영상 단계에서 스타일이 이탈하지 않도록 함
- **BGM 단일 트랙 원칙**: 씬별로 따로 생성하지 않고 44초 분량 1개 트랙을 생성 후 편집 단계에서 볼륨만 조정 → 오디오 톤 미스매치 방지

## 크레딧/대기열 이슈 대응 (제약사항 반영)
1. 이미지 생성 단계에서 5씬 전체 키비주얼을 먼저 확정 (재생성 최소화)
2. 확정된 이미지만 Veo 비디오 변환 단계로 진행 (영상 생성 크레딧 절약)
3. Primary 도구(Gemini)가 팀 계정 쿼터/대기열 문제 시 즉시 Backup 도구로 전환, 고정 스타일 키워드는 동일하게 유지해 톤 차이 최소화
