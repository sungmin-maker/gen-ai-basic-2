## 1. 브랜드 아이덴티티 — Lumin

| 항목 | 내용 |
|---|---|
| 브랜드명 | Lumin (루민) |
| 카테고리 | 스마트 무드등 + 홈 스캔트(디퓨저) 일체형 기기 |
| 한 줄 정의 | 버튼 하나로 조명과 향이 함께 바뀌는, 저녁 루틴을 위한 스마트 디바이스 |

| 톤앤매너 | 따뜻한 앰버 조명, 미니멀 인테리어, 로파이 사운드, 느리고 차분한 편집 리듬 |

**USP**
1. 조명 색온도와 향의 조합이 프리셋으로 연동 (예: "휴식 모드" = 앰버 조명 + 우디 향)
2. 앱 없이 다이얼 하나로 조작
3. 향 카트리지 자동 인식 및 잔량 알림

**캠페인 목표**: 브랜드 인지(Awareness) + 초기 관심 유도
**핵심 메시지**: "당신의 저녁에, 쉼표를 켜다."
**스토리 구조**: 기승전결 (기: 지친 퇴근 → 승: 다이얼로 전환 시작 → 전: 조명·향 변화 → 결: 편안해진 인물 + 브랜드 노출)

## 4. 트러블슈팅 기록 (실제 겪은 문제 → 해결)

과제 제약사항의 "도구 접근성 대응"을 실제로 적용해본 사례입니다. 학생들에게 **"AI 생성이 막히면 이렇게 원인을 좁혀가라"**는 예시로 보여주기 좋습니다.

### 사례 1: Veo 영상 생성 오류의 진짜 원인 찾기
1. **증상**: 씬1 이미지를 참고로 첨부하고 Veo에 영상 생성 요청 → `"I can't generate that video"` 오류
2. **1차 추정(오판)**: 인물 묘사가 콘텐츠 정책에 걸린 것으로 판단 → 인물을 완전히 제거한 프롬프트로 재시도 → **동일 오류 재발**
3. **2차 추정(오판)**: 콘텐츠 정책이 아니라 계정 권한/크레딧 문제로 재판단 → 무료 대안 도구(Kling AI)로 전환 검토
4. **실제 원인**: 전환 직전, **참고 이미지 없이 텍스트만으로** 마지막 재시도 → **정상 작동**. 즉 원인은 콘텐츠 정책도 권한 문제도 아닌, **"이미지 첨부 방식(image-to-video) 자체에 대한 제한"**이었음
5. **최종 결정**: Gemini(Veo)를 그대로 사용하되, 텍스트 전용 프롬프트로 파이프라인 확정. 이미지 프롬프트의 구도/색감 묘사를 영상 프롬프트에도 그대로 포함시켜 두 결과물의 톤을 최대한 맞춤
6. **배운 점**: 같은 오류가 반복되면 원인을 한 번에 단정하지 말고, "입력 방식"처럼 변수를 하나씩 분리해 재현 테스트할 것

### 사례 2: 클립 길이 제한 발견
- Veo는 클립당 **최대 8초**(4/6/8초 중 선택)만 지원한다는 사실을 뒤늦게 확인
- 10초 이상으로 설계했던 씬3·씬4를 8초로 축소, 전체 길이를 44초 → 38초로 재조정 (요구사항 30~60초 범위는 유지)

### 사례 3: BGM 도구 전환 (Suno → Gemini)
- Suno 무료 계정은 생성한 트랙을 **다운로드할 수 없다**는 제약을 뒤늦게 발견
- 대체 도구를 새로 가입하는 대신, 이미 접근 가능한 Gemini 생태계 내에서 BGM을 생성하는 방식으로 전환

전체 프롬프트 수정 전/후 상세 기록: [`docs/04_prompts.md`](docs/04_prompts.md)

## 6. 통합 편집 계획

편집 도구는 **컷 편집/자막/간단한 색보정·오디오 레벨 조정**으로만 제한 사용하고, 핵심 비주얼/오디오는 AI 생성물을 그대로 유지합니다.

- 타임라인: 씬1(0–8s) → 씬2(8–14s) → 씬3(14–22s) → 씬4(22–30s) → 씬5(30–38s), 하드컷 기본 + 씬2→3, 씬4→5만 디졸브
- 오디오: 통 내레이션을 씬 구간에 맞춰 분할 배치, BGM은 내레이션 구간에서 덕킹(-12dB)
- 자막/브랜드 노출: 이미지·영상 자체에는 텍스트를 생성하지 않았으므로(AI 텍스트 왜곡 방지), 편집 단계에서 실제 폰트로 "Lumin" 워드마크 + 슬로건을 삽입
- 씬5 워터마크 의심 아이콘은 크롭/비네트로 제거
- 내보내기 스펙: 1920x1080, 30fps, H.264/AAC

세부 내용: [`docs/05_editing_plan.md`](docs/05_editing_plan.md)

**현재 상태**: 위 계획은 수립되었으나, **최종 MP4 조립(NLE 작업)은 아직 진행 전**입니다. 실제 학생 제출 시에는 이 단계까지 완료한 1개의 완성 MP4 파일이 필요합니다.

## 8. 학생 안내 시 강조 포인트 (강사용 메모)

1. **완벽하게 처음 계획대로 되지 않는다** — 이 프로젝트에서만 도구가 2번 바뀌었다(Veo 입력 방식, BGM 도구). 계획 문서를 고정된 것으로 보지 말고, 문제가 생기면 왜 바뀌었는지 기록하며 유연하게 대응하는 과정 자체가 평가 포인트라는 것을 강조
2. **같은 오류가 반복되면 변수를 하나씩 분리해서 테스트** — "인물 유무"가 원인인 줄 알았지만 실제로는 "이미지 첨부 여부"였던 사례를 예시로 보여줄 것
3. **무료 플랜의 숨은 제약을 먼저 확인** — 다운로드 가능 여부, 클립 길이 상한 등은 실제로 써봐야 아는 경우가 많음. 크레딧을 다 쓰기 전에 확인하도록 안내
4. **AI에 텍스트/로고를 직접 생성시키지 말 것** — 왜곡 위험이 크므로, 여백만 확보하고 편집 단계에서 실제 폰트로 삽입하는 전략을 권장
5. **일관성은 "여러 방법의 조합"으로 확보** — 스타일 코드(`--sref` 등)가 없는 도구에서는 고정 키워드 반복, 실루엣 전략, 단일 세션 연속 생성 같은 대체 전략을 조합해야 함
